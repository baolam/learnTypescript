# 📘 TypeScript Mastery Tutorial

> **Tuyển tập kiến thức thực hành và bài tập TypeScript từ căn bản đến nâng cao.**

## 📑 Các chuyên đề học tập
- `intro/`: Giới thiệu cấu trúc TypeScript và cấu hình `tsconfig.json`.
- `variable/`: Các kiểu dữ liệu nguyên thủy (Primitive Types).
- `array/` & `tuple/`: Mảng, Tuple và kỹ thuật bất biến (Readonly).
- `object/` & `interface/`: Định nghĩa kiểu đối tượng, kế thừa interface và hợp đồng dữ liệu.
- `enums/`: Cách khai báo và sử dụng Numeric & String Enums.
- `union/`: Hợp kiểu (Union Types) và Type Narrowing.
- `function/`: Định nghĩa tham số tuỳ chọn, mặc định, Rest parameters và hàm trả về.
- `pureTs/`: Lập trình hướng đối tượng (OOP), Generics, Access Modifiers (`public`, `private`, `protected`).

## 🚀 Bắt đầu
```bash
# Cài đặt TypeScript toàn cục
npm install -g typescript

# Biên dịch file
tsc filename.ts

# Hoặc chạy trực tiếp với ts-node
npx ts-node filename.ts
```
